# Local Setup

This skeleton is prepared for the public Revit Operator core.

1. Copy `.env.example` to `.env`.
2. Set `REVIT_OPERATOR_MODE=local`.
3. Set `OPERATOR_API_BASE_URL=http://127.0.0.1:7007`.
4. Install dependencies for the backend, desktop UI, and Revit add-in once source code is copied in.
5. Run the local backend and Revit add-in build scripts documented in the source tree.

Do not commit real `.env` files.
